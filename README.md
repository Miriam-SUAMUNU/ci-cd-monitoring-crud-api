

 API CRUD – DevOps / CI-CD / Monitoring
 Description

API REST conteneurisée permettant la gestion d’utilisateurs (CRUD), développée dans un objectif de mise en pratique des principes DevOps, CI/CD et monitoring.

Ce projet met en œuvre une architecture complète incluant Docker, reverse proxy, logs structurés et supervision applicative.

 Architecture

API REST Node.js

Base de données MariaDB

Reverse proxy Nginx

Logs structurés JSON (application & infrastructure)

Docker & Docker Compose

 Fonctionnalités

CRUD utilisateurs (Create, Read, Update, Delete)

Endpoint de health check

Centralisation et structuration des logs

Séparation claire des services applicatifs

Architecture prête pour une intégration CI/CD

👩‍💻 Travail réalisé

Conception et développement d’une API REST

Conteneurisation des services avec Docker

Mise en place d’un reverse proxy Nginx

Configuration de logs applicatifs et Nginx en JSON

Mise en œuvre de bonnes pratiques DevOps (observabilité, reproductibilité)

 Technologies

Node.js

Docker / Docker Compose

Nginx

MariaDB

REST API

Logs & monitoring

 Contexte

Projet réalisé dans un cadre universitaire (DevOps / CI-CD / Monitoring), avec une approche orientée environnement de production et bonnes pratiques professionnelles.
